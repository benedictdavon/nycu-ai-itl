# guidelines

## What AI tools we plan to use
* We will use ChatGPT for brainstorming implementation ideas, explaining unfamiliar concepts, and helping debug small code issues. We will not rely on it to make final design decisions without team discussion.
* We will use GitHub Copilot for inline code completion and generating simple boilerplate code while programming. All generated code must be reviewed and tested by a team member before being merged.
* We will use ChatGPT to generate first drafts of unit tests and documentation. A human will check the correctness, add missing edge cases, and revise the final version.
* We will not use AI-generated code directly for security-sensitive features such as authentication, authorization, or handling sensitive user data without careful human review.
