# Samples

Everything under `samples/` is made up and in English. No real people, strains, labs or data.

- `members.json`: the sample lab members.
- `records/`: upload records for seeding and tests. Each `NN-slug.json` is the answer key (the expected `M`) for the `NN-slug.txt` with the same stem.
- `discussions/`: made-up chats to paste into "save the discussion" for the D3-4 demo.
